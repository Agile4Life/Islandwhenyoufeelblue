# Island When You Feel Blue — 3D Tropical Island Diorama

Single-file interactive 3D Isometric Tropical Island Diorama built with **Three.js `r128`** and **OrbitControls**.

## Highlights

- **4 Dynamic Weather Modes (`Keys 1–4`):** Sunny (`Nắng đẹp`), Sunset (`Hoàng hôn`), Tropical Rain (`Mưa rào`), and Thunderstorm (`Giông bão` with 3D forked lightning).
- **Panoramic Ocean Horizon & Multi-Layer Celestial Sun:** Curved open-ocean horizon, seamless procedural solar disc with limb-darkening, sunset mirage bands, corona, starburst rays, crepuscular God-rays, and a 3-tier shimmering Sun-Path reflection stretching across the ocean (`ánh suốt biển`).
- **Living Archipelago & Dynamic Fleet:**
  - **3 Moving Boats:** Outrigger Catamaran sailboat, Island Sloop sailboat, and a Lagoon Outrigger Canoe with an animated rower and V-shaped wake foam trails.
  - **6 Articulated Island Visitors & Water Sports:** Beach strollers, coastal jogger, stepping-stone trail hiker up to the Bamboo Tiki Overlook, Stand-Up Paddleboarder (SUP), and lagoon swimmer.
  - **Rich Ecosystem:** Multi-tier lotus waterfall, coral reef & 42 swimming reef fish, beach crabs, swaying coconut palms, hammock, driftwood campfire, wooden jetty, rowboat, seagulls, and drifting clouds.
- **60 FPS GPU-Optimized Architecture:** Merged static buffer geometries, `InstancedMesh` batching (`<= 200` draw calls), and fast algebraic GLSL shaders.

## Run Locally

Open `index.html` directly in any modern WebGL-capable browser (Chrome, Edge, Firefox, Safari), or serve the folder via any static HTTP server / GitHub Pages.
